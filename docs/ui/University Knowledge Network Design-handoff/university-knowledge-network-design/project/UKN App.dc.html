Responsive rules

≥1200px
Header + left sidebar + main + right sidebar. Main column stays dominant.
992–1199px
Right sidebar drops to 260px; mentor grid becomes one column.
768–991px
Left sidebar collapses to icons; right sidebar modules move under the feed.
<768px
Offcanvas nav, two header rows, tables become stacked cards.
